System design · PCS

Arquitetura frontend escalável — Almaviva

Case técnico do portal portuário: base preparada para evolução contínua, crescimento de equipa e integração com sistemas complexos — além das telas da galeria, o desenho de camadas e de estado foi documentado de forma explícita.

Visão geral e diagrama

O trabalho não foi só construir interfaces: estruturar uma base sólida inspirada em Clean Architecture e DDD, com camadas bem definidas — Presentation, Application, Domain e Infrastructure.

Decisões de arquitetura

A estrutura responde a problemas típicos de aplicações grandes:

  • Reduzir acoplamento entre UI e regras de negócio
  • Estado previsível e testável
  • Manutenção e evolução de features em paralelo

Abordagens: arquitetura em camadas; feature-first (vertical slices); separação de estados (global, servidor e UI); hooks como orquestração.

Gestão de estado
  • Server state — APIs, cache e revalidação
  • Global state — autenticação, preferências partilhadas
  • UI state — comportamento e controlo visual
  • Local / URL state — filtros e navegação persistidos

Esta separação reduz complexidade e evita conflitos comuns em SPAs de grande porte.

Estrutura e fluxo de dados

Feature-first

Cada funcionalidade com a sua árvore: hooks, schemas, componentes, tipagens e regras de negócio — para squads paralelos sem perder organização.

Fluxo

Interface → hooks → camada de aplicação → APIs → persistência. Interceptors para autenticação, erros e padronização de pedidos.

Stack e visão IA-ready

Stack: React, TypeScript, TanStack Query, Zustand, Zod, Vite — foco em performance, escalabilidade e DX.

IA-ready: domínio desacoplado da infraestrutura facilita integrações futuras (automação de fluxos, recomendações, análise em tempo real) sem reescritas traumáticas.

Resultado e conclusão

Resultado: escalar funcionalidades com menos risco, reduzir complexidade ao longo do tempo, melhorar testabilidade e velocidade de entrega.

Em suma: preocupação explícita com engenharia, organização e sustentabilidade do código — o tipo de decisão que sustenta ambientes corporativos e sistemas críticos.
